# План разработки

## Цель проекта

SkillSwap — веб-приложение для поиска партнёров по взаимному обучению. Пользователь описывает свои сильные навыки и навыки, которые хочет развить, после чего получает рекомендации, отправляет запросы на обмен, планирует учебные сессии и фиксирует прогресс через отзывы.

## Пользовательские сценарии

1. Регистрация и вход: пользователь создаёт аккаунт, входит, получает защищённый dashboard.
2. Заполнение профиля: пользователь редактирует имя, город, bio, добавляет навыки teach/learn.
3. Поиск партнёра: пользователь фильтрует людей по навыку, категории, уровню и отправляет swap request.
4. Обучение: пользователь принимает запрос, видит матч, создаёт сессию и оставляет отзыв.

## Риски

1. Несовместимость Angular/Taiga версий — фиксировать версии в `package.json`, проверять production build.
2. Слишком большой объём фич — держать MVP: auth, profile, discover, requests, matches, sessions.
3. Потеря данных mock API — использовать seed data и `localStorage`, добавить reset при необходимости.
4. Формальное использование UI kit — применять Taiga в формах, карточках, tabs, badges, loader, buttons.
5. Нестабильные e2e — тестировать только ключевые сценарии с предсказуемыми seed data.
