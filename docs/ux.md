# UX-концепция

## Целевая аудитория

**Самостоятельный ученик.** Хочет быстро найти человека для практики без оплаты и без долгого поиска в чатах. Ему важны понятные фильтры, рейтинг и быстрый запрос на обмен.

**Наставник-практик.** Готов делиться сильным навыком, но хочет получать пользу взамен. Ему важны входящие запросы, расписание сессий и репутация через отзывы.

## User stories

- Как пользователь, я хочу указать навыки, которым могу обучать, чтобы получать релевантные предложения.
- Как пользователь, я хочу выбрать навык для изучения, чтобы найти людей, которые могут мне помочь.
- Как пользователь, я хочу принять или отклонить запрос, чтобы контролировать свои матчи.
- Как пользователь, я хочу запланировать сессию и оставить отзыв, чтобы отслеживать обучение.

## Дизайн-система

Основа — Taiga UI 5:

- `tui-input`, `tui-textarea`, `tui-select` для форм;
- `tui-button` для команд;
- `tui-tabs` для входящих/исходящих запросов;
- `tui-badge` для статусов и навыков;
- `tui-card` для панелей, карточек партнёров и метрик;
- `tui-loader` для loading states;
- `tui-root`, `tui-dialog`/overlay pattern для модальных сценариев.

Визуальный стиль: спокойный рабочий интерфейс с зелёным акцентом, тёплым вторичным цветом и плотной dashboard-компоновкой. Карточки имеют умеренный радиус, интерфейс адаптирован под desktop/tablet/mobile.

## Первый экран

Для гостя первый экран объясняет обмен навыками и даёт CTA регистрации. Для авторизованного пользователя первый экран — dashboard: метрики, рекомендации и последние запросы.
